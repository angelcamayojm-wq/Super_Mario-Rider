## 🎨 ✨ Características Clave

* 🌌 **Fondo Interactivo:** Video en bucle de alta definición con sistema de control de audio general (*Mute/Unmute*).
* 💎 **Diseño Neon Glassmorphism:** Interfaz visual retro-moderna con paneles semitransparentes, efectos de brillo y responsive design adaptado a cualquier pantalla.
* 📱 **Navegación Dinámica por Pestañas:** Transición rápida y fluida entre módulos sin necesidad de recargar la página.
* 🎨 **Studio Maker (Canvas API):** Plataforma para dibujar escenarios, cambiar fondos temáticos (Castillo, Underground), trazar rectángulos, círculos, líneas y descargar la creación en PNG.

---

## 🛠️ 💻 Tecnologías Utilizadas

* **HTML5 Semántico:** Estructura limpia y optimizada para accesibilidad.
* **CSS3 Avanzado:** Flexbox, Grid Layout, variables CSS, animaciones y diseño Glassmorphism.
* **JavaScript (ES6+):** Manipulación dinámica del DOM, gestión de eventos, integración de Canvas API y reproductores multimedia.
